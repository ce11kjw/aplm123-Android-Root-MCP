# MCP 低 Token 高可靠工作流

## 渐进披露

1. 工具发现只返回紧凑输入约束，不重复发送可离线获取的完整输出 Schema。
2. 自动技能只返回最多几个 ID、标题和摘要；需要时再读取一个完整技能。
3. 工具结果的结构化对象只发送一次；文本区只保留短状态，不复制整份 JSON。
4. 命令、网页、日志和任务输出设定小型内联预览，完整内容写入 artifact。
5. 长任务先返回 taskId；含凭据、正文、命令或带 query 的 URL 不得转成持久后台参数。任务进入终态后先写脱敏完成回执，再删除快照 arguments。
## 可靠性

每个写操作都保留 machine-readable code、strategy、duration 和验证结果。中断后只自动恢复只读且幂等的任务；其他任务先读回状态再显式重提。学习记录用随机收据 ID、单调事件序号和技能代次，不依赖设备墙钟判断最新或遗忘。
